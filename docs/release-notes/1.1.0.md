# Chunk Mob Challenge 1.1.0

Eine gemeinsame Plugin-JAR für Paper **26.1.x (26.1.1/26.1.2), 26.2 und 26.3**
mit Java 25.

- Gegen die älteste verfügbare Ziel-API 26.1.1 gebaut.
- API-Inkompatibilität beim Zurücksetzen der Größe eines Challenge-Enderdrachens
  behoben: Der Standardwert wird am Attribut des Mobs abgefragt.
- Automatische API-Builds und isolierte Serverchecks für alle vier Zielversionen,
  auch vor GitHub Releases.
- Testserver-Skripte, gepinnte Downloads und Dokumentation erweitert.
- Pluginversion und JAR-Version werden gemeinsam aus Gradle erzeugt.

Neue Mobs werden weiterhin zur Laufzeit erkannt. Eine bereits angepasste
`mobs.yml` wird nicht automatisch um neue Einträge ergänzt; zum Erzeugen des
vollständigen versionsabhängigen Pools die Datei bei gestopptem Server löschen.

Paper stellt für 26.1/26.1.0 keinen eigenen Download bereit. Für 26.1.1 ist nur
ein Alpha-Build verfügbar. Vollständige manuelle Gameplay-Tests für 26.1.1 und
26.3 stehen noch aus; die automatischen Checks prüfen Laden, Mobpool, Status,
Reload und Shutdown. Bisherige Gameplay-Ergebnisse stehen in `TESTING.md`.

## Update

1. Server mit `stop` beenden und Welt sowie `plugins/ChunkMobChallenge` sichern.
2. Bisherige Plugin-JAR durch `chunk-mob-challenge-1.1.0.jar` ersetzen.
3. Server starten und `/cc status` prüfen.

Bestehende Konfiguration und gespeicherte Runs bleiben kompatibel. `/cc stop`
beendet und löscht einen Run weiterhin bewusst.
